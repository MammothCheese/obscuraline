# =====================================================================================================================
#  OBSCURA LINE - THE CHAPTERS (from Mechanica Obscura's puzzles, with the train between the stations)
# =====================================================================================================================
#
#  Every chapter of the game, IN PLAY ORDER. Each [block] is one chapter:
#
#      [chapter_id]                 lower case, digits, _   (its words live in script.txt under [chapter chapter_id])
#      type        = escapement     which mechanism it uses (the list of types is at the end of this file)
#      station     = clockworks     (any type) the station it belongs to, on the map (content/lines.txt)
#      unlocks     = horn           (optional) what solving it adds to the train: key stopwatch horn whistle lights call synth voice
#      opens       = leg_id ...     (optional) the lines it opens (both ways; a line no chapter opens is open once reached)
#                                   (key: the map, and the train itself). The first chapter's station is where it starts
#      setting     = value          that type's settings; leave one out and its default is used
#
#  Values:   a number           beat_ms     = 200
#            a range            rate_error  = 4..11       (the game picks inside it each time: puzzles vary)
#            a list             teeth       = 10 12 15 16
#            several lines      tune        = 3 5 8 5 ...  (repeat the key: one entry a line; the game picks one)
#
#  To EDIT a puzzle:            change its settings here (and its words in script.txt).
#  To ADD a puzzle of a type:   copy a block, give it a new id and place it where it should come in the story;
#                               add a [chapter new_id] with its words to script.txt. Nothing else.
#  To REMOVE or REORDER:        move or delete blocks (and their script.txt sections).
#  A new TYPE of mechanism:     needs C code; see content/README.txt.
#
#  Then build as usual (./build.sh, or tests/run_host.sh on a computer). tools/content.py checks both files and
#  stops with the file and line if something is wrong. `python3 tools/content.py --types` lists every type and
#  every setting with its limits. At most 16 chapters.
#
# =====================================================================================================================
